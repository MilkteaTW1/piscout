1. 要重灌哪一台？

進階：遠端重灌（有風險）
遠端重灌是在「執行中」的樹莓派上覆寫它自己的 SD 卡。如果中途關閉程式、斷電、 斷網或電腦睡眠，那張卡會變成寫了一半、開不了機，而且無法從遠端修復，只能把卡拿到電腦上重燒。 請先準備讀卡機或備用的 SD 卡。
必須是還開得起來、而且開著 SSH 的樹莓派。完全空白的 SD 卡在網路上看不到， 請改選「插在這台電腦上的 SD 卡」。重灌會清空這台 Pi 的所有資料。
